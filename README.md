# BOOKA — Sistema de Gestión para Salones

BOOKA es un sistema de gestión profesional diseñado para salones, optimizado para entornos multiusuario en red local (LAN). Inspirado en modelos de licenciamiento offline, ofrece control total y seguridad para la administración de tu negocio.

## Características Principales

*   **Gestión Offline:** Funciona 100% sin depender de una conexión constante a Internet.
*   **Multiusuario LAN:** Arquitectura servidor-cliente para conectar múltiples puestos de trabajo en tu salón.
*   **Licenciamiento Seguro:** Basado en HWID (Hardware ID) único por equipo, garantizando el uso exclusivo de tu licencia.
*   **Activación Flexible:** 
    *   **Vía Presencial:** Activación inmediata durante la instalación técnica.
    *   **Vía Remota:** Generación de licencias mediante códigos de solicitud/activación.
*   **Seguridad:** Detección de manipulación de fecha del sistema y firma digital para proteger la integridad de la licencia.
*   **Flujo de Primer Uso:** Configuración guiada del administrador principal y acceso seguro al sistema.

## Soporte y Licenciamiento

BOOKA utiliza un modelo de licencias por tiempo, adaptable a las necesidades de cada salón. 

*   **Soporte:** Para dudas, activación de licencias o adquisición de nuevos puestos cliente, por favor contacta al desarrollador a través de los canales de venta oficiales.
*   **Soporte Técnico:** Soporte prioritario vía WhatsApp durante el periodo de vigencia de tu licencia.
